콘솔의 **독자** 그룹은 스태프가 사이트를 읽는 사람들을 상대하는 곳입니다. 독자의 계정, 독자가 에피소드에 남기는 댓글, 문의 양식으로 보내는 메시지, 그리고 결제 없이 유료 에피소드를 독자 한 명에게 열어 주는 이용권을 다룹니다. 여기서 하는 일은 독자에게 직접 영향을 주며 되돌릴 방법이 없는 경우도 있으므로, 각 페이지는 조치하는 방법보다 그 조치가 무엇을 하는지를 먼저 설명합니다.

모든 스태프가 모든 화면을 보는 것은 아닙니다.

| 화면       | 테넌트 관리자 | 편집 담당     | 감사 담당      |
| ---------- | ------------- | ------------- | -------------- |
| **독자**   | 모든 작업     | 표시되지 않음 | 표시되지 않음  |
| **댓글**   | 모든 작업     | 모든 작업     | 조치 없이 열람 |
| **문의**   | 모든 작업     | 표시되지 않음 | 표시되지 않음  |
| **이용권** | 모든 작업     | 표시되지 않음 | 표시되지 않음  |

표시되지 않는 화면은 메뉴에 나오지 않으며, 그 주소는 존재하지 않는 페이지로 응답합니다.

## 이 섹션의 내용

- [독자 계정](./1-accounts.md): 독자의 계정 찾기, 생년월일 정정, 아이콘 삭제, 계정 정지와 삭제.
- [댓글](./2-comments.md): 댓글의 각 상태가 뜻하는 것, 댓글의 승인, 숨기기, 복원, 완전 삭제, 그리고 승인 대기열과 신고 대기열 처리.
- [문의](./3-contact-messages.md): 독자가 보내는 메시지의 담당자 지정과 답변, 독자의 회신이 도착하는 곳, 처리 상황 관리.
- [이용권](./4-access-tickets.md): 결제 없이 유료 에피소드를 독자 한 명에게 열어 주기와 이용권 취소.

## 커뮤니티 제한이 적용되는 방식

**설정** › **제한 및 보존**의 **커뮤니티 제한**은 독자 한 명이 얼마나 자주 행동할 수 있는지 제한합니다. 테넌트 관리자는 각 제한을 플랫폼의 제한보다 엄격하게 할 수는 있지만 느슨하게 할 수는 없으며, [제한 및 보존](../3-setup/1-settings.md#제한-및-보존)에서 설명합니다.

| 제한 | 독자가 제한에 걸리는 행동 |
| --- | --- |
| **댓글 작성**(분당, 일당) | 댓글을 더 작성하는 것 |
| **댓글 신고**(분당, 일당) | 댓글을 더 신고하는 것 |
| **계정당 문의**(시간당, 일당) | 로그인한 독자가 메시지를 더 보내는 것 |
| **클라이언트당 문의**(시간당, 일당) | 로그인 여부와 관계없이 누구든 같은 네트워크 주소에서 메시지를 더 보내는 것 |
| **중복 댓글 판정 시간** | 그 시간(분) 안에 같은 에피소드에 같은 내용을 다시 작성하는 것 |

제한을 넘은 독자에게는 "짧은 시간에 요청이 너무 많습니다. 잠시 후 다시 시도해 주세요."라는 메시지가 표시되며, 해당 기간이 지나면 다시 행동할 수 있습니다. **중복 댓글 판정 시간** 안에 같은 댓글을 반복하는 독자에게는 사이트와 앱에서 "방금 등록한 댓글입니다. 같은 내용은 잠시 후에 다시 등록할 수 있습니다."라는 메시지가 표시됩니다.

독자나 스크립트가 댓글이나 문의 양식을 도배하고 있을 때는 제한을 강화하세요. 한 명의 독자가 원인이라면 [독자](./1-accounts.md#독자-정지하기)에서 계정을 정지하세요. 제한은 사이트와 앱에서 독자가 하는 행동을 세며, 스태프가 그곳에서 댓글을 다는 경우도 포함됩니다. 모더레이터가 콘솔에서 하는 일은 세지 않습니다. 각 제한이 무엇을 세는지는 운영자 쪽에서 [플랫폼 기본값과 정책](../../3-operations/9-platform-policies.md#커뮤니티)에서 설명합니다.
