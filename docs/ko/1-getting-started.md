Publira는 출판사가 자사 브랜드로 운영하는 만화 판매·배포 플랫폼입니다. 출판사와 편집자는 작가에게서 받은 작품을 페이지 이미지로 이루어진 시리즈와 에피소드로 등록하고, 독자는 웹이나 모바일 앱에서 작품을 구매해 읽습니다. Publira는 오픈 소스이며 일반적인 인프라에서 동작하도록 만들어져 있으므로, 설치 환경이 특정 클라우드 사업자에 묶이지 않습니다.

## 이 문서의 대상 독자

이 문서는 Publira 설치 환경을 운영하는 사람을 위해 쓰였습니다. 설치 환경을 배포하고 계속 가동하는 운영자, 그리고 콘솔에서 사이트를 설정하는 출판사의 스태프입니다. 각 페이지는 하나의 작업이나 하나의 질문에 답하며, 실제로 마주칠 가능성이 높은 순서대로 배치되어 있습니다.

Publira 자체를 변경하려면 저장소에서 시작하세요. [CONTRIBUTING.md](https://github.com/publira/publira/blob/main/CONTRIBUTING.md)에 저장소의 구성, 툴체인, 풀 리퀘스트의 리뷰 방식이 설명되어 있습니다.

## Publira 설치 환경이 제공하는 것

하나의 설치 환경은 하나 이상의 출판사를 서비스하며, 각 출판사를 테넌트라고 부릅니다. 각 테넌트에는 다음이 제공됩니다.

- 테넌트 자체 도메인의 공개 사이트. 독자가 카탈로그를 둘러보고, 로그인하고, 작품을 읽는 곳입니다.
- 두 번째 호스트 이름의 콘솔. 출판사의 스태프가 작품, 에피소드, 독자, 사이트 설정을 관리하는 곳입니다.

선택 사항인 플랫폼 콘솔을 사용하면 운영자가 브라우저에서 모든 테넌트를 관리할 수 있습니다. 플랫폼 콘솔이 없으면 운영자는 `publiractl` 명령줄로 설치 환경을 관리합니다.
