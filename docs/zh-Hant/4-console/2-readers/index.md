主控台的**讀者**群組，是工作人員處理網站讀者相關事務的地方：他們的帳戶、他們在章節上留下的留言、他們透過聯絡表單寄來的訊息，以及不需付款就向其中某位讀者開放付費章節的閱讀券。在這裡所做的事會直接影響讀者，有時甚至無法復原，因此每一頁都會先說明某個操作會造成什麼結果，再說明如何進行。

並不是每位工作人員都能看到每個畫面：

| 畫面       | 租戶管理員 | 編輯   | 稽核員             |
| ---------- | ---------- | ------ | ------------------ |
| **讀者**   | 全部       | 不顯示 | 不顯示             |
| **留言**   | 全部       | 全部   | 可閱讀，但無法操作 |
| **諮詢**   | 全部       | 不顯示 | 不顯示             |
| **閱讀券** | 全部       | 不顯示 | 不顯示             |

不顯示的畫面不會出現在選單中，它的位址也會以不存在的頁面回應。

## 本節內容

- [讀者帳戶](./1-accounts.md)：尋找讀者的帳戶、更正其出生日期、刪除其頭像，以及暫停或刪除帳戶。
- [留言](./2-comments.md)：留言的各種狀態代表什麼、通過、移除、恢復與永久刪除留言，以及處理審核與檢舉佇列。
- [諮詢](./3-contact-messages.md)：指派與回覆讀者寄來的訊息、他們的回信會送到哪裡，以及追蹤哪些已處理。
- [閱讀券](./4-access-tickets.md)：不需付款就向一位讀者開放付費章節，以及撤銷閱讀券。

## 社群限制如何套用

**設定** › **限制與保留**下的**社群限制**，限制一位讀者可以多頻繁地進行操作。租戶管理員可以讓每項限制比平台的限制更嚴格，但永遠不能更寬鬆，如[限制與保留](../3-setup/1-settings.md#限制與保留)所述：

| 限制 | 讀者會在什麼時候碰到 |
| --- | --- |
| **發表留言**，每分鐘與每天 | 發表更多留言時 |
| **檢舉留言**，每分鐘與每天 | 檢舉更多留言時 |
| **每個帳號的聯絡訊息**，每小時與每天 | 已登入的讀者寄送更多訊息時 |
| **每個用戶端的聯絡訊息**，每小時與每天 | 任何人（不論是否登入）從同一個網路位址寄送更多訊息時 |
| **重複留言判定時間** | 在該分鐘數內再次於同一個章節發表相同的文字時 |

超過限制的讀者會看到「短時間內的請求過多。請稍後再試。」，並在該期間過後才能再次操作。在**重複留言判定時間**內重複發表留言的讀者，會在網站與應用程式上看到「您剛剛已發表過這則留言。相同的內容需過一段時間才能再次發表。」

當某位讀者或某個腳本大量灌入留言或聯絡表單時，請收緊限制；如果只是一位讀者，請在[讀者](./1-accounts.md#暫停讀者)中暫停該帳戶。這些限制計算的是讀者在網站與應用程式上的操作，工作人員在那裡留言時也包括在內；管理者在主控台中的操作則不計入。每項限制計算什麼，在[平台預設值與政策](../../3-operations/9-platform-policies.md#社群)中從營運人員的角度說明。
