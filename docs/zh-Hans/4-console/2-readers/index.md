控制台的**读者**分组是工作人员处理网站读者相关事务的地方：读者的账户、他们在章节下留下的评论、他们通过咨询表单发送的消息，以及无需付款即可向某位读者开放付费章节的阅读券。在这里进行的操作会直接影响读者，有时无法撤销，因此每一页都会先说明某个操作的作用，再说明如何执行。

并非每位工作人员都能看到所有界面：

| 界面       | 租户管理员 | 编辑   | 审计员           |
| ---------- | ---------- | ------ | ---------------- |
| **读者**   | 全部       | 不显示 | 不显示           |
| **评论**   | 全部       | 全部   | 可查看，不可操作 |
| **咨询**   | 全部       | 不显示 | 不显示           |
| **阅读券** | 全部       | 不显示 | 不显示           |

不显示的界面不会出现在菜单中，访问其地址时会返回页面不存在。

## 本章内容

- [读者账户](./1-accounts.md)：查找读者的账户、更正其出生日期、删除其头像，以及暂停或删除账户。
- [评论](./2-comments.md)：评论各状态的含义，通过、移除、恢复和彻底删除评论，以及处理审核队列和举报队列。
- [咨询](./3-contact-messages.md)：分配和回复读者发送的消息、读者的回复会发到哪里，以及跟踪处理进度。
- [阅读券](./4-access-tickets.md)：无需付款向某位读者开放付费章节，以及撤销阅读券。

## 社区限制如何生效

**设置** › **限制与保留**中的**社区限制**限定单个读者执行操作的频率。租户管理员可以让每项限制比平台的更严格，但不能更宽松，如[限制与保留](../3-setup/1-settings.md#限制与保留)所述：

| 限制 | 读者会受到限制的操作 |
| --- | --- |
| **发表评论**，每分钟和每天 | 继续发表评论 |
| **举报评论**，每分钟和每天 | 继续举报评论 |
| **每个账户的联系消息**，每小时和每天 | 已登录的读者继续发送消息 |
| **每个客户端的联系消息**，每小时和每天 | 任何人从同一网络地址继续发送消息，无论是否登录 |
| **重复评论判定时间** | 在该分钟数内再次在同一章节下发表相同内容 |

超出限制的读者会看到“短时间内的请求过多。请稍后再试。”，时间段过去后即可再次操作。在**重复评论判定时间**内重复发表评论的读者，会在网站和应用中看到“您刚刚已发表过这条评论。相同的内容需过一段时间才能再次发表。”

当某位读者或某个脚本大量涌入评论或咨询表单时，请收紧限制；如果只是某一位读者，请在[读者](./1-accounts.md#暂停读者)中暂停其账户。这些限制统计的是读者在网站和应用中的操作，工作人员在那里发表评论时也包括在内；审核人员在控制台中进行的操作不计入。每项限制统计什么，请参阅从运营人员角度说明的[平台默认值与策略](../../3-operations/9-platform-policies.md#社区)。
