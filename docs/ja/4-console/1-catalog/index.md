読者がサイトで開くものは、どれもシリーズに含まれるエピソードです。シリーズはいずれかのレーベルに属し、著者をクレジットします。サイドバーの**作品**グループには、これらを作成する画面と、エピソードの公開日を確認するカレンダーがあります。

| 画面 | 扱うもの |
| --- | --- |
| **シリーズ** | 作品と、作品に含まれるエピソード |
| **カレンダー** | 公開予約済みと公開済みのすべてのエピソード。それぞれの公開日に表示されます |
| **レーベル** | シリーズを刊行するレーベル |
| **著者** | シリーズやエピソードにクレジットされる人 |
| **著者の役割** | **Original Author**や**Artist**など、著者をクレジットするときの役割 |
| **ジャンル** | 読者が作品を探すときに使う分類 |

![サイドバーの作品グループ。シリーズ、カレンダー、レーベル、著者、著者の役割、ジャンルが並んでいます。](./index-catalog-group.png)

テナント管理者と編集担当は、これらの画面で何でも作成し、変更できます。例外は著者に紐付けた**読者アカウント**で、表示と変更ができるのはテナント管理者だけです。監査担当はどの画面も開けますが、フォームは読み取り専用で、作成用のボタンも表示されません。作品まわりで削除できるのは、エピソードのページと、どこにも使われていない著者の役割とジャンルだけです。もう読ませたくないシリーズやエピソードは、削除する代わりにサイトでの公開をやめます。

## 最初のエピソードを公開するまで

管理画面では、次の順番で作業する必要があります。シリーズはレーベルがないと保存できません。著者は作成済みの著者の中から選んでクレジットします。エピソードはシリーズの中に作ります。最初のエピソードを準備している間はシリーズを非公開にしておき、最後の手順でシリーズとエピソードをまとめて読者に公開します。

1. **レーベルを作成します。** **レーベル**で**レーベルを新規作成**を選び、**レーベル名**を入力して**レーベルを作成**を選びます。レーベルが1つしかない出版社は、このレーベルを1つだけ作り、以降のシリーズもすべてこのレーベルに入れます。シリーズごとにレーベルを作る必要はありません。詳しくは[レーベル](./3-labels.md)を参照してください。
2. **著者を作成します。** **著者**で、クレジットする人ごとに**著者を新規作成**を選びます。**名前**を入力し、用意があれば**プロフィール**と**著者アイコン画像**も設定します。詳しくは[著者と役割](./4-authors.md)を参照してください。
3. **著者の役割を確認します。** 新しいテナントには**Original Author**、**Artist**、**Writer**、**Supervisor**の4つの役割が英語で用意されています。役割は読者に著者名と並べて表示されるので、サイトが英語以外の言語なら**著者の役割**で名前を変えておきます。
4. **ジャンルを作成します。** サイトでジャンルを使う場合は、**ジャンル**で作成します。シリーズはジャンルがなくても保存でき、ジャンルはあとから設定できます。詳しくは[ジャンル](./5-genres.md)を参照してください。
5. **シリーズを作成します。** **シリーズ**で**シリーズを新規作成**を選びます。**タイトル**と**概要**、**レーベル**を入力し、**著者**で著者をクレジットして、**アイキャッチ画像**を選びます。**公開日時**は空欄のままにしておくと、作業中はシリーズが非公開のままになります。最後に**シリーズを作成**を選びます。詳しくは[シリーズ](./1-series.md)を参照してください。
6. **最初のエピソードを作成します。** **シリーズ**の一覧で対象のシリーズの行にある**エピソード**を選び、**新規作成**を選びます。**タイトル**と**価格**を入力し、**公開日時**に現在の時刻を設定します。こうするとエピソードは作成と同時に公開されますが、シリーズがまだ非公開なので、この時点では読者は読めません。**エピソードを作成**を選びます。詳しくは[エピソード](./2-episodes.md)を参照してください。
7. **ページを追加します。** エピソードの編集画面の**漫画ページ追加**でページ画像を追加し、**登録済みページ画像**で並び順を確認します。
8. **シリーズを公開します。** シリーズの編集画面に戻り、**公開日時**に現在の時刻を設定して**シリーズを更新**を選びます。これでシリーズと最初のエピソードがサイトに公開されます。
9. **読者として開いてみます。** ログアウトするかプライベートウィンドウを使い、サイトのトップページか**レーベル**、またはタイトルでの検索からシリーズを探します。エピソードを開いてページをめくってみてください。有料のエピソードではページの代わりに価格が表示されます。有料エピソードの開き方は[エピソードの販売](../4-selling-episodes.md)で説明しています。

2話目以降のエピソードは、すでに公開中のシリーズに追加することになります。そのため下書きとして準備し、ページがそろってから公開日時を設定します。手順は[エピソードの公開](./2-episodes.md#エピソードの公開)で説明しています。

## このセクションの内容

- [シリーズ](./1-series.md)では、シリーズの作成、表示する場所と時期、年齢制限、読む方向、コメント、アイキャッチ画像、**待てば無料**を説明します。
- [エピソード](./2-episodes.md)では、エピソードの作成、ページの追加、価格と閲覧期間、ページレイアウト、クレジット、表示する場所と販売する場所、無料公開期間、予約公開と、いつ何が公開されるかを確認するカレンダーを説明します。
- [レーベル](./3-labels.md)では、シリーズを刊行するレーベルと、読者が見るレーベルのページを説明します。
- [著者と役割](./4-authors.md)では、作品にクレジットされる人とその役割、サイトでのクレジットの表示、著者と読者アカウントの紐付けを説明します。
- [ジャンル](./5-genres.md)では、読者が作品を探すときの分類と、その並び順を説明します。
