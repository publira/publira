読者は、サイトのすべてのページのフッターとアプリにあるリンク**お問い合わせ**から、ログインしているかどうかにかかわらず、サイトにメッセージを送れます。読者は、回答の送り先のメールアドレス、200文字までの任意の件名、4000文字までのメッセージを入力します。ログインした読者のメールアドレスはあらかじめ入力されていて、変更できます。

新しいメッセージは、有効なすべてのテナント管理者のアカウントのメールアドレスに、読者のメールアドレス、件名、メッセージ全文とともにメールで送られます。編集担当と監査担当は**お問い合わせ**を開けないので、メールは送られません。停止中のアカウントにも送られません。有効なテナント管理者がいないテナントでは、メールはだれにも送られませんが、メッセージは**お問い合わせ**で待っています。管理画面自体は新しいメッセージの件数や通知を表示しないので、**お問い合わせ**を確認するか、そのメールに注意しておいてください。

**お問い合わせ**には、メッセージが新しい順に、1ページに20件ずつ、**件名**、**差出人**、**返信先**、**状態**、**担当者**、**受信日時**とともに表示されます。**差出人**には、読者がログインしていた場合は読者のアカウントが、そうでなければ**ゲスト**と表示されます。**状態**はメッセージの状況から決まり、手動で設定することはありません。

| 状態         | 条件                                               |
| ------------ | -------------------------------------------------- |
| **未対応**   | 対応済みでなく、だれも割り当てられていない         |
| **対応中**   | 対応済みでなく、テナント管理者が割り当てられている |
| **対応済み** | 対応済みにされたか、回答された                     |

## メッセージへの回答

1. **お問い合わせ**からメッセージを開きます。
2. **担当者の割り当て**で、**自分に割り当てる**を選ぶか、テナント管理者を選んで**担当者を保存**を選び、対応中であることをほかの人にわかるようにします。割り当てられるのはテナント管理者だけです。
3. **回答**に4000文字までで回答を書き、**回答を送信**を選びます。

![対応中のお問い合わせ。「対応済みにする」のあるメッセージ、回答欄と「回答を送信」のある回答と返信、「自分に割り当てる」と「担当者を保存」のある担当者の割り当て、「メモを保存」のあるスタッフメモ。](./contact-messages-message.png)

回答は**回答と返信**に保存され、メッセージは**対応済み**になります。そして`publira worker`が、メッセージの**返信先**のアドレスに回答をメールで送ります。

- 送信には[メール](../3-setup/7-email.md)で設定したメールサーバーを使い、そのアドレスから送ります。テナントが独自のメールサーバーを持つまでは、プラットフォームのメールサーバーを使います。
- 件名は「Re:」に読者の件名を続けたものです。読者が件名を入力しなかった場合は、「Re: （サイト名）へのお問い合わせ」です。
- 回答の下に、読者のメッセージが引用されます。
- 読者がどの言語で書いたかにかかわらず、テナントのデフォルトの言語で送られます。

管理画面には、メールが届いたかどうかは表示されません。メールの設定が誤っていると、回答は保存され、メッセージは**対応済み**になったまま、メールは送られません。そのため、テナントが独自のサーバーから送信している場合は、読者に回答する前に**送信メール**の**接続テスト**で確認してください。1つのアドレスへの回答は、管理画面が送るすべてのメールと同じく、1時間あたりと1日あたりの件数が制限されています。

## 読者が返信してきたとき

読者の返信がどこに届くかは、**外部連携** › **メール情報**の**受信メール**のセクションが**利用可能**かどうかによります。設定の手順は[お問い合わせへの読者の返信](../3-setup/7-email.md#お問い合わせへの返信に対する読者の返信)で説明しています。

- **利用可能になるまでは**、回答の返信先アドレスはあなた自身のアカウントのメールアドレスです。読者の返信はあなた自身のメールボックスに届きます。返信は管理画面に記録されず、メッセージは**対応済み**のままです。回答は自分のメールから送るか、もう一度管理画面から送ってください。
- **利用可能になったあとは**、返信先アドレスは、そのメッセージのために作られたサイト独自のアドレスになります。読者の返信は**回答と返信**に「（読者のアドレス）からの返信」として記録され、メッセージは再び開かれた状態になり、新しいメッセージと同じようにテナント管理者にメールが送られます。

**回答**の下のヒントに、テナントにどちらが当てはまるかが表示されます。

## 対応状況の管理

- **スタッフメモ**は、テナント管理者がメッセージについて共有する1つのメモで、4000文字までです。読者には表示されません。保存するとすべての人に対して置き換わり、空で保存すると消去されます。
- **対応済みにする**は、スパムなど、回答せずに対応を終えたメッセージに印を付けます。**対応済みを取り消す**は、メッセージを**対応中**または**未対応**に戻します。どちらも担当者は変えません。

メッセージが削除されることはなく、保持期間もありません。あとでアカウントを削除した読者からのメッセージも保持され、**ゲスト**からのものとして表示されます。対応済みにすること、対応済みの取り消し、担当者の割り当て、メモの編集、回答は監査ログに記録されます。回答の本文は記録されません。
