管理画面の**読者**グループでは、サイトを読む人たちへの対応を行います。扱うのは、読者のアカウント、読者がエピソードに書いたコメント、お問い合わせフォームから届いたメッセージ、有料エピソードを特定の読者に無料で開放するアクセスチケットです。ここでの操作は読者に直接届き、元に戻せないものもあるので、各ページでは手順より先にその操作で何が起きるかを説明しています。

表示される画面はスタッフのロールによって異なります。

| 画面 | テナント管理者 | 編集担当 | 監査担当 |
| --- | --- | --- | --- |
| **読者** | すべての操作 | 表示されない | 表示されない |
| **コメント** | すべての操作 | すべての操作 | 閲覧のみ(操作はできない) |
| **お問い合わせ** | すべての操作 | 表示されない | 表示されない |
| **アクセスチケット** | すべての操作 | 表示されない | 表示されない |

表示されない画面はメニューに出ず、URLを直接開いても存在しないページとして扱われます。

## このセクションの内容

- [読者アカウント](./1-accounts.md)では、読者のアカウントの探し方、生年月日の訂正、アイコンの削除、アカウントの利用停止と削除を説明します。
- [コメント](./2-comments.md)では、コメントの各状態の意味、コメントの承認、非表示、復元、完全削除と、承認待ちと通報の処理を説明します。
- [お問い合わせ](./3-contact-messages.md)では、読者から届いたメッセージの担当者の割り当てと返信、読者からの返信が届く場所、対応状況の管理を説明します。
- [アクセスチケット](./4-access-tickets.md)では、有料エピソードを1人の読者に無料で開放する方法と、チケットの失効を説明します。

## コミュニティの上限

**設定** › **制限と保持**の**コミュニティの上限**では、1人の読者が一定時間内に操作できる回数を制限します。テナント管理者は、各上限をプラットフォームの上限より厳しくできますが、緩めることはできません。詳しくは[制限と保持](../3-setup/1-settings.md#制限と保持)を参照してください。

| 上限 | 上限に達したときに制限される操作 |
| --- | --- |
| **コメント投稿**(1分あたり、1日あたり) | コメントの投稿 |
| **コメント報告**(1分あたり、1日あたり) | コメントの通報 |
| **アカウントごとの問い合わせ**(1時間あたり、1日あたり) | ログインしている読者によるメッセージの送信 |
| **クライアントごとの問い合わせ**(1時間あたり、1日あたり) | 同じネットワークアドレスからのメッセージの送信。ログインしているかどうかは問いません |
| **重複コメントの判定時間** | 指定した分数以内に、同じエピソードへ同じ文面のコメントをもう一度投稿すること |

上限を超えた読者には「短時間に操作が集中しています。少し時間をおいて再試行してください。」と表示されます。期間が過ぎれば、また操作できます。**重複コメントの判定時間**内に同じコメントを投稿しようとした読者には、サイトでもアプリでも「このコメントはさきほど投稿済みです。同じ内容は、しばらく時間をおいてから投稿できます。」と表示されます。

読者やスクリプトがコメントやお問い合わせフォームに大量に送信してくるときは、上限を厳しくします。送信しているのが1人の読者なら、[読者](./1-accounts.md#読者の利用停止)でそのアカウントを利用停止にします。上限が数えるのは読者がサイトとアプリで行う操作で、スタッフがサイトやアプリでコメントした場合も含まれます。モデレーターが管理画面で行う操作は数えません。各上限が何を数えるかは、オペレーター向けの[プラットフォーム全体の既定値とポリシー](../../3-operations/9-platform-policies.md#コミュニティ)で説明しています。
