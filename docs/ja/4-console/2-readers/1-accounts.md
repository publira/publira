**読者**には、テナントのサイトのすべてのアカウントが、登録日の新しい順に、1ページに20件ずつ表示されます。管理画面のアカウントはサイトのアカウントでもあるので、スタッフもここに含まれます。**ロール**にはスタッフが持つ最も上位のロールが表示され、読者の場合は空欄です。この画面はテナント管理者にだけ表示されます。

人を探すには、名前またはメールアドレスの一部を**名前またはメールアドレス**に入力し、**適用**を選びます。検索はどちらの中のどの位置でも一致し、大文字と小文字を区別しないので、`tanaka`で`Tanaka Hanako`も`h.tanaka@example.com`も見つかります。**状態**で一覧を1つの状態に絞り込めます。

| 状態 | 意味 |
| --- | --- |
| **有効** | アカウントでログインできます |
| **無効** | 読者が会員登録したものの、まだメールアドレスを確認していません。確認するまでログインできません |
| **停止中** | テナント管理者がアカウントを停止しました。停止が解除されるまでログインできません |

各行の先頭には、読者がアカウントに設定したアイコンが表示されます。設定していない読者には、簡素な輪郭だけの画像が表示されます。**コメント**でも、投稿者のアイコンが同じように表示されます。一覧の読者の名前を選ぶと、その読者のページが開きます。テナント管理者の場合は、**コメント**の投稿者の名前と、ログインした状態で送られたお問い合わせの差出人からも開けます。

## 読者のページ

**アカウント**には、読者の**アイコン**、名前、コピーするボタンの付いた**公開ID**、メールアドレス、状態、登録日、メールアドレスを確認したかどうかとその日時、**生年月日**が表示されます。

その下の3つのセクションには、読者が持っているものが新しい順に、1ページに20件ずつ表示されます。

| セクション | 表示されるもの |
| --- | --- |
| **購入** | 読者が購入したすべてのもの。購入の対象（エピソード、巻、シリーズの残り、コインのパック）、金額、支払いに使ったもの、購入したものがまだ読めるかどうか。タイトルを選ぶと購入したものが開き、**表示**を選ぶと**購入**でその購入が開き、そこで返金できます |
| **アクセスチケット** | スタッフがその読者に発行したチケットと、そのエピソードとチケットの状態。**失効**と**チケットを発行**は、[アクセスチケット](./4-access-tickets.md)と同じように、ページを離れずに使えます |
| **コメント** | 読者が書いたすべてのコメント。読者が自分で削除したコメントも、完全削除されるまでは含まれます。[コメント](./2-comments.md)と同じ操作ができます |

## 生年月日の訂正

読者は、いったん保存した生年月日を変更できません。そのため、誤って入力した読者はサイトに依頼する必要があり、[年齢確認](../3-setup/1-settings.md#年齢確認)で設定した年齢の確認は、保存されている値に従います。訂正するには、**生年月日**の横の**変更**を選び、日付を入力して**保存**を選びます。日付を空にすると生年月日が消去され、読者は年齢制限のあるシリーズで再び生年月日を求められます。新しい日付は、読者が次に読むときから適用されます。

## 読者のアイコンの削除

読者のアイコンは、コメントの横に表示され、サイトを読むすべての人の目に触れます。そのため、サイトのルールに反するアイコンはここから取り下げます。**アイコン**の横の**アイコンを削除**を選び、**削除する**で確定します。画像はすぐにサイトと管理画面に表示されなくなり、アカウントには代わりに簡素な輪郭だけの画像が表示されます。読者は、自分でアイコンを削除したときと同じように、あとで別のアイコンを設定できます。

**アイコンを削除**は、アカウントにアイコンが表示されている間だけ表示されます。

読者がアイコンをアップロードできるか、テナントが用意したアイコンから選べるか、アイコンをまったく表示しないかは、[読者のアイコン](../3-setup/1-settings.md#読者のアイコン)で説明するとおり、**設定**で決めます。

## 読者の停止

**停止**は、読者をすべての端末からログアウトさせ、停止が解除されるまで、パスワードでも、AppleやGoogleでも、ログインを拒否します。アカウントのほかの点は何も変わりません。公開済みのコメントはサイトに残り、購入とアクセスチケットも読者のもののままです。使えないのはログインできない間だけです。

同じページにある**停止を解除**は、アカウントを**有効**に戻します。メールアドレスが一度も確認されていない場合は**無効**に戻ります。読者は再びログインします。停止によって終了したセッションは終了したままです。停止中の読者を探すには、**状態**を**停止中**にします。

## 読者の削除

**削除**は、読者が自分で退会したのとまったく同じようにアカウントを削除します。元に戻すことはできません。

| 読者が持っていたもの | どうなるか |
| --- | --- |
| コメントと、読者が行った通報 | 削除されます |
| 購入 | 購入者の情報を除いて保持されます。そのため、売上と印税は変わりません |
| プランのサブスクリプション | テナントのStripeアカウントで直ちにキャンセルされ、読者に再び請求されることはありません。すでに支払った期間の分は返金されません |
| アクセスチケット、フォロー、閲覧履歴、評価、通知、連携しているAppleとGoogleのログイン | 削除されます |
| お問い合わせ | 保持され、**ゲスト**からのものとして表示されます |
| スタッフとしてのロール | 外されます |

元に戻したくなる可能性がある場合は、削除ではなく停止にしてください。

ログイン中の自分のアカウントと、テナントで最後の有効なテナント管理者は、停止も削除もできません。先にほかの人をテナント管理者にしてください。停止、停止の解除、削除、生年月日の変更と消去、アイコンの削除は、[監査ログ](../3-setup/8-audit-log.md)に、それぞれ**読者の停止**、**読者の停止解除**、**読者削除**、**読者の生年月日変更**、**読者の生年月日の消去**、**読者のアイコン削除**として記録されます。
