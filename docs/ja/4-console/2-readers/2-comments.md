読者がエピソードにコメントできるのは、コメントの受け付けが有効になっている場合だけです。テナント全体では**設定** › **読者のコメント**で、シリーズごとにはシリーズのフォームで設定します。3つの選択肢(**受け付けない**、**すぐに公開する**、**承認してから公開する**)と、何件の通報でコメントを自動で非表示にするかは、[読者のコメント](../3-setup/1-settings.md#読者のコメント)で説明しています。

コメントを投稿できるのはログインしている読者だけで、1件1000文字までです。コメントはエピソードごとに付き、返信やスレッドの機能はありません。そのため、1件のコメントに対する操作がほかのコメントに影響することはありません。

**コメント**には2つの一覧があります。上に**通報されたコメント**、その下にテナントのエピソードに付いたすべてのコメントが新しい順に表示されます。監査担当にも両方の一覧が表示されますが、操作のボタンは表示されません。

## コメントの状態

| 状態 | コメントが見える人 |
| --- | --- |
| **承認待ち** | 投稿者だけです。投稿者には**承認待ち**と表示されます |
| **公開中** | 全員です |
| **非表示** | 投稿者だけです。投稿者には投稿したときのまま表示されます |
| **投稿者が削除** | サイトでは投稿者を含めて誰にも見えません。完全削除されるまでは、スタッフがこの画面で確認できます |

## 各操作の内容

| 操作 | 操作できる状態 | 内容 |
| --- | --- | --- |
| **承認** | **承認待ち** | コメントを公開し、投稿者にコメントが公開されたことを通知します |
| **非表示** | **承認待ち**、**公開中** | 投稿者以外の人にはコメントが表示されなくなります。「**理由（任意）**」に入力した内容は監査ログに記録されます |
| **元に戻す** | **非表示** | コメントを非表示にする前の状態に戻します。公開されていたコメントは再び公開され、そうでなければ**承認待ち**に戻ります。そのコメントに対する未処理の通報は、すべて却下されます |
| **完全削除** | すべての状態 | コメントとその通報を完全に削除します。削除後にコメントについて残るのは監査ログの記録だけなので、**理由**の入力が必須です |

コメントを非表示にしても、投稿者には知らされません。モデレーターが非表示にした場合も、読者の通報で非表示になった場合も同じです。投稿者にはコメントが投稿したときのまま見え続けるので、コメント欄を荒らす目的で投稿している人に、再投稿のきっかけを与えずに済みます。

一覧を読み込んだあとで別のモデレーターが同じコメントを処理していた場合は、操作が受け付けられず、「他の担当者がこのコメントをすでに処理しました。一覧を再読み込みして現在の状態を確認してください。」と表示されます。

## 承認待ちのコメントの処理

承認待ちのコメントがあるときは、メニューの**コメント**にその件数が表示されます。また、スタッフ全員に、管理画面の通知で「承認待ちのコメントがあります」が届きます。通知はエピソードごとに1時間に1回までです。通知を開くと、そのエピソードの承認待ちのコメントに絞り込んだ一覧が表示されます。

1. **コメント**を開き、**状態**で**承認待ち**を選んで**適用**を選びます。
2. コメントを1件ずつ読み、公開するなら**承認**を、サイトに出さないなら**非表示**を選びます。
3. 一覧が空になるまで、ページを送りながら処理します。

コメントは承認されるまで投稿者以外の誰にも見えません。承認待ちのコメントを処理せずにおくと、コメント欄は空のままです。承認待ちの状態から非表示にしたコメントは、投稿者には引き続き**承認待ち**と表示されます。

## 通報されたコメント

ログインしている読者は、自分以外の人が書いた公開中のコメントを通報できます。通報するときは**スパム・宣伝**、**暴言・嫌がらせ**、**ネタバレ**、**その他**から理由を選び、必要ならメモを添えます。同じ読者が同じコメントを通報できるのは1回だけで、もう一度通報しても何も変わりません。通報されたことは投稿者には知らされません。

コメントへの未処理の通報が**自動で非表示にする報告件数**に達すると、スタッフの判断を待たずにコメントが自動で非表示になります。このときも投稿者には知らされません。そのコメントには「通報がしきい値を超えたため自動で非表示になりました。」と表示され、監査ログには**通報によるコメントの自動非表示**が、操作者を**自動処理**として記録されます。また、スタッフ全員に、管理画面の通知で「コメントが報告されました」が届きます。通知はエピソードごとに1時間に1回までです。

**通報されたコメント**には、通報1件ごとに1行が新しい順に表示されます。各行には、通報の理由、メモ、通報者、コメント、コメントの投稿者が表示されます。通報は判断するまで**未処理**のままです。

- **妥当と判断**を選ぶと、通報が正しかったことを記録します。コメント自体は変わりません。公開中のコメントを非表示にするには、あわせて**非表示**を選びます。
- **却下**を選ぶと、通報が誤りだったことを記録します。自動で非表示になったコメントは、却下しても元に戻りません。元に戻すには**元に戻す**を選びます。

![通報されたコメント。すべての状態、未処理、妥当と判断、却下の絞り込みがあり、公開中のコメントへの未処理の通報が1件表示されています。通報には理由とメモ、通報に対する妥当と判断と却下のボタン、コメントに対する非表示と完全削除のボタンがあります。](./comments-reports.png)

通報を処理するときは、絞り込みを**未処理**にして、コメントごとに残すかどうかを決めます。残さない場合は、コメントを**非表示**にし、その通報を**妥当と判断**にします。残す場合、コメントが非表示になっていれば**元に戻す**を選びます。これで未処理の通報はまとめて却下されます。非表示になっていなければ、通報を1件ずつ**却下**します。通報を判断すると、自動で非表示にするまでの件数に数えられなくなります。そのため、却下した通報があとからコメントをしきい値に届かせることはありません。

## 投稿者が削除したコメント

読者は自分のコメントをいつでも削除できます。削除したコメントは、本人を含めて誰からもすぐに見えなくなり、スタッフが元に戻すことはできません。**コメント**では引き続き**投稿者が削除**として表示され、削除された日時と完全削除される予定の日時も表示されます。そのため、通報や苦情のあったコメントを投稿者が削除したあとでも、スタッフは内容を確認できます。そのコメントへの通報は一覧に残り、引き続き判断できます。

投稿者が削除したコメントは、**設定** › **制限と保持** › **保持期間** › **取り下げられたコメント**で設定した期間が過ぎると、通報と一緒に完全削除されます。完全削除は`publira worker`が1時間ごとに行います。各行には「あと30日、2026/02/04 10:00に完全削除されます。」のように、現在の設定の期間で数えた残りの日数と日時が表示されます。期間を待たずに削除するには**完全削除**を選びます。非表示にしたコメントが自動で完全削除されることはなく、モデレーターが完全削除するまで残ります。

## コメントの検索

コメントの一覧は、**状態**、**シリーズのpublic_id**、**エピソードのpublic_id**で絞り込めます。公開IDは、管理画面でシリーズやエピソードを開いたときのURLの末尾の部分で、`/series/<series public ID>/episodes/<episode public ID>`のような形になっています。各コメントの**エピソード**は、そのURLへのリンクになっています。どれにも一致しないIDを指定すると、一覧は空になります。

エピソードにクレジットされた著者に紐付けたアカウントで書かれたコメントには、サイトでもこの画面でも**著者**バッジが付きます。バッジが付いても、モデレーションの方法は変わりません。

コメントの承認、非表示、復元、完全削除と、通報の妥当と判断、却下は、入力した理由と一緒に監査ログに記録されます。
