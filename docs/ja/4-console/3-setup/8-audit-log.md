**管理**グループの**監査ログ**には、スタッフが管理画面で行った操作がテナントごとに記録されています。誰がいつ何を変更し、その操作が成功したかがわかるので、誰が読者を停止したのか、誰が決済の設定を変えたのか、いつメンバーにロールが付与されたのかといったことを調べられます。この画面は、テナント管理者にしか表示されません。

## ログの見方

各エントリーには、次の内容が表示されます。

- **日時**は、テナントのタイムゾーンで表示されます。
- **操作者**には、操作したスタッフと、その公開ID、操作したときのロールが表示されます。一定数の読者から報告されたコメントが非表示になったときのように、プラットフォームが自動で行った操作には**自動処理**と表示されます。
- **アクション**には操作の内容が表示され、その下に操作した対象の種類とIDが表示されます。理由を記録する操作では、その理由も表示されます。
- **結果**は、**成功**か**失敗**です。2段階認証でログインするときにコードを間違えた場合や、メールサーバーの接続テストが通らなかった場合のように、失敗した操作も記録されます。

エントリーは新しい順に、1ページに20件ずつ並びます。絞り込むには、**開始日**と**終了日**、**アクション**、**操作者**を指定して**適用**を選びます。**開始日**と**終了日**は、テナントのタイムゾーンでの日単位で指定します。**リセット**を選ぶと、絞り込みの条件が消えます。

![2026年4月で絞り込んだ監査ログ。開始日、終了日、アクション、操作者の絞り込みと「適用」、「リセット」があり、その横に「CSVをダウンロード」がある。エントリーには日時、公開IDとロール付きの操作者、対象付きのアクション、結果が表示されている。](./audit-log-list.png)

エントリーは削除されません。スタッフのアカウントが後で削除されても、エントリーにはそのスタッフの名前と公開IDが残ります。

## ログのダウンロード

絞り込みの横にある**CSVをダウンロード**を選ぶと、表示中の期間、**アクション**、**操作者**に当てはまるエントリーが、古い順に1つのCSVファイルとして保存されます。ファイル名は、`audit-log-<tenant>-2026-04-01--2026-04-30.csv`のようにテナントの公開IDと期間から付けられます。1つのファイルに含められるのは最長366日分です。**終了日**を指定しなければ期間は今日までになり、**開始日**を指定しなければ**終了日**(指定がなければ今日)までの366日間になります。それより長い期間や、**開始日**が**終了日**より後になっている期間は、期間を狭めるまでダウンロードできません。

CSVの列と、表計算ソフトがテキストとして開けるようにするファイルの形式は、[ログのエクスポート](../../3-operations/12-security/3-audit-logs.md#ログのエクスポート)で説明しています。ダウンロードもそのたびに**監査ログのCSVダウンロード**としてログに記録されるので、誰がどの期間のログを持ち出したかもわかります。

## 記録される操作

| 分野 | 記録される操作 |
| --- | --- |
| 作品 | シリーズ、エピソード、巻、著者、著者の役割、レーベル、ジャンルの作成と変更。巻の販売開始、販売停止、並べ替え。言語ごとのシリーズとエピソードのタイトルの削除。著者の役割とジャンルの削除。これらの画像のアップロード。無料公開期間と待てば無料の変更 |
| サイト | ページの作成と変更。ページのバージョンの作成、公開、ロールバック。ページの翻訳の追加と削除。ページの公開の取り下げ。お知らせの作成とバナーの取り下げ。キャンペーンバナーの作成、変更、並べ替え、削除と、バナー画像のアップロード |
| コメント | コメントの承認、削除、復元、完全削除。報告による自動削除。報告の承認と却下 |
| 読者 | 読者の停止、復元、削除。読者の生年月日の変更と消去。読者のアイコンの削除。アクセスチケットの発行と取り消し。購入の返金の申請と実行。お問い合わせの対応済みへの変更、再開、担当者の割り当て、メモの追加、回答 |
| 印税 | 締めの設定の変更、月の締め、明細のCSVダウンロード |
| アナリティクス | **売上**、**読者の反応**、**離脱**からのレポートのCSVダウンロード |
| 監査ログ | ログのCSVダウンロードと、その対象期間 |
| スタッフ | メンバーの招待。招待の再送、取り消し、承諾。ロールの変更。メンバーの削除 |
| ブランディング | テーマの変更。ロゴ、アイコン、ログインフォームの横の画像、外部サービスのロゴのアップロードと削除 |
| 設定 | **基本情報**タブの公開サイト表示設定、タイムゾーン、既定言語、読者のコメント、年齢確認、利用規約とプライバシーポリシー、受け付けないメールアドレス。**制限と保持**のコミュニティの上限と保持期間。読者がアイコンとして表示できるものと、プリセットのアイコンの追加と削除 |
| 外部連携 | メールの設定とその接続テスト、決済プロバイダの設定、**販売先**、モバイルプッシュの認証情報、**アプリリンク**に登録したアプリ、ログインのプロバイダー、Googleタグ |
| 2段階認証 | スタッフによる2段階認証の設定、無効化、リカバリーコードの再発行、2段階認証やリカバリーコードを使ったログイン |

メンバーが自分のメールアドレスを変更しても、エントリーは残りません。読者がサイトで行った操作も記録されません。

テナントのドメインや管理者のロールのように、オペレーターがプラットフォーム管理画面や`publiractl`でテナントについて変更した内容は、このログではなく、プラットフォーム管理画面のログに記録されます。
