このセクションは、[デプロイ](../2-deployments/index.md)の手順を終えて、すでにサービスを始めているPubliraのオペレーター向けです。最初のテナントを作ったあとの作業を扱います。テナントの追加、各管理画面にログインできる人の管理、プラットフォーム自体のアカウントの管理、`publiractl setup`で設定したサービスの変更です。

これらの作業のほとんどは、`publiractl`のコマンドラインとプラットフォーム管理画面のどちらからでも行えます。どちらを使うかは最初のページで説明します。以降のページでは、両方の方法がある作業について両方の手順を示します。

## このセクションの内容

- [プラットフォーム管理画面とpubliractl](./1-platform-console.md)では、2つの使い分け、最初のオペレーターの作成、プラットフォーム管理画面にログインするオペレーターについて説明します。
- [テナント](./2-tenants.md)では、テナントの作成、ドメインと管理画面のホスト、それらの変更、テナントの停止を説明します。
- [テナントのスタッフ](./3-tenant-staff.md)では、テナントの管理画面にログインする人とそのロール、招待、最後の管理者がいなくなったテナントの復旧を説明します。
- [ユーザー](./4-users.md)では、すべてのテナントの読者と、オペレーターが読者のアカウントに対してできることを説明します。
- [オブジェクトストレージ](./5-object-storage.md)では、すべての画像を保存するバケットとその認証情報、画像を変換、キャッシュして`/images`で配信するしくみを説明します。
- [メール](./6-email.md)では、プラットフォームのSMTPアカウントとテナント独自のアカウント、Publiraが送るメール、HTMLメール、メール内のリンクの行き先を説明します。
- [検索](./7-search.md)では、公開サイトの検索エンジン、データベースからOpenSearchやElasticsearchへの移行、テキスト解析、インデックスの再構築を説明します。
- [Web Push](./8-web-push.md)では、ブラウザー通知の有効化と、通知の署名に使う鍵ペアを説明します。
- [プラットフォーム全体の既定値とポリシー](./9-platform-policies.md)では、すべてのテナントが引き継ぐ既定値、セキュリティとコミュニティの制限、保存期間と、そのうちテナントが変更できるものを説明します。
- [定期ジョブとメンテナンスジョブ](./10-scheduled-jobs.md)では、`publira worker`が自動で実行する処理、停止していたあとに遅れを取り戻すしくみ、送信するメール、プッシュ通知、キャッシュの再検証の再試行、`publiractl job`によるジョブの手動実行を説明します。
- [監視](./11-monitoring.md)では、どのプロセスも応答するヘルスチェックとその確認方法、アラートを設定すべきログとメトリクス、OpenTelemetryのメトリクスとトレースの有効化を説明します。
- [セキュリティ](./12-security/index.md)では、テナントどうしや認証情報を分離するしくみと、各シークレットを置いてよい場所を説明します。
  - [シークレットのローテーション](./12-security/1-rotating-secrets.md)では、暗号化キー、データベースのパスワード、署名キー、トークンの入れ替えを説明します。
  - [2段階認証](./12-security/2-two-step-verification.md)では、テナントのスタッフとプラットフォームのオペレーターに2段階認証を必須にする方法を説明します。
  - [監査ログ](./12-security/3-audit-logs.md)では、プラットフォーム管理画面のログとテナントのログに記録される内容と、どちらにも記録されない内容を説明します。
  - [レート制限とWAF](./12-security/4-rate-limits.md)では、クライアントごとに制限するリクエストと、その制限をWAFやリバースプロキシでかける方法を説明します。

Publiraについてまだ読んでいない場合は、[はじめに](../1-getting-started.md)から読んでください。
