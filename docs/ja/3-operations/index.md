このセクションは、[デプロイ](../2-deployments/index.md)の手順を終え、すでにサービスを提供しているインストールのオペレーターに向けたものです。最初のテナントを作ったあとの作業として、テナントの追加、各管理画面にログインできる人の管理、プラットフォーム自体のアカウントの整理、`publiractl setup`で設定したサービスの変更を扱います。

ほとんどの作業は、`publiractl`のコマンドラインとプラットフォーム管理画面のどちらでも行えます。どちらを使うかの判断は最初のページで説明し、以降のページでは両方の方法がある作業について両方の手順を示します。

## このセクションの内容

- [プラットフォーム管理画面とpubliractl](./1-platform-console.md)では、2つの使い分け、最初のオペレーターの作成、プラットフォーム管理画面にログインするオペレーターを説明します。
- [テナント](./2-tenants.md)では、テナントの作成、ドメインと管理画面のホストの決め方と変更、テナントの停止を説明します。
- [テナントのスタッフ](./3-tenant-staff.md)では、テナントの管理画面にログインする人とそのロール、招待、最後の管理者を失ったテナントの復旧を説明します。
- [ユーザー](./4-users.md)では、すべてのテナントの読者と、そのアカウントに対してオペレーターができることを説明します。
- [オブジェクトストレージ](./5-object-storage.md)では、すべての画像を保存するバケット、その認証情報、画像を変換してキャッシュし`/images`で配信するしくみを説明します。
- [メール](./6-email.md)では、プラットフォームのSMTPアカウントとテナント独自のアカウント、Publiraが送るメール、HTMLメール、メール内のリンクの行き先を説明します。
- [検索](./7-search.md)では、公開サイトの検索エンジン、データベースからOpenSearchやElasticsearchへの切り替え、テキスト解析、インデックスの再構築を説明します。
- [Web Push](./8-web-push.md)では、ブラウザー通知を有効にする方法と、通知の署名に使う鍵ペアを説明します。
- [プラットフォーム全体の既定値とポリシー](./9-platform-policies.md)では、すべてのテナントが引き継ぐ既定値、セキュリティとコミュニティの制限、保存期間を取り上げ、そのうちテナントが変更できるものを説明します。
- [定期ジョブとメンテナンスジョブ](./10-scheduled-jobs.md)では、`publira worker`が自動で実行する処理、停止していたあとの遅れの取り戻し方、メールとプッシュ通知とキャッシュの再検証の再試行、`publiractl job`によるジョブの手動実行を説明します。
- [監視](./11-monitoring.md)では、すべてのプロセスが応答するヘルスチェックとその確認方法、アラートを設定すべきログとメトリクス、OpenTelemetryのメトリクスとトレースの有効化を説明します。
- [セキュリティ](./12-security/index.md)では、テナントどうしや認証情報を分離するしくみと、各シークレットを置いてよい場所を説明します。
  - [シークレットのローテーション](./12-security/1-rotating-secrets.md)では、暗号化キー、データベースのパスワード、署名キー、トークンの入れ替え方を説明します。
  - [2段階認証](./12-security/2-two-step-verification.md)では、テナントのスタッフとプラットフォームのオペレーターに2段階認証を必須にする方法を説明します。
  - [監査ログ](./12-security/3-audit-logs.md)では、プラットフォーム管理画面のログとテナントのログに記録される内容と、どちらにも記録されない内容を説明します。
  - [WAF](./12-security/4-waf.md)では、有効にするマネージドルールと、PubliraのアップロードやWebhookのために必要な例外を説明します。
  - [レート制限](./12-security/5-rate-limits.md)では、インストールの前段でクライアントごとに制限するリクエストと、その制限をWAFのルールや自分で運用するリバースプロキシに書く方法を説明します。

Publiraがどういうものかをまだ読んでいない場合は、[はじめに](../1-getting-started.md)から読んでください。
