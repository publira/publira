# Switch

スイッチ（トグル）コンポーネントです。[Base UI Switch](https://base-ui.com/r/components/switch) をベースに実装しています。

## 使用方法

```tsx
import { Switch } from "@publira/ui-components";

export default function Example() {
  return <Switch />;
}
```

## Subpath import

```tsx
import { Switch } from "@publira/ui-components/switch";
```

## Props

Base UI Switch のプロップに準じます。詳細は [Base UI Switch documentation](https://base-ui.com/r/components/switch) を参照してください。
