# Switch

A switch (toggle) component, implemented on top of [Base UI Switch](https://base-ui.com/r/components/switch).

## Usage

```tsx
import { Switch } from "@publira/ui-components";

export default function Example() {
  return <Switch />;
}
```

## Subpath import

```tsx
import { Switch } from "@publira/ui-components/switch";
```

## Props

Follows the props of Base UI Switch. See the [Base UI Switch documentation](https://base-ui.com/r/components/switch) for details.
